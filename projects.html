Enterprise Windows Home Lab (Featured Project)

Project Repository: GitHub - Enterprise IT Lab

My Enterprise Windows Home Lab is my largest ongoing technical project and serves as a personal learning environment focused on Windows Server administration, Active Directory, cloud infrastructure, and enterprise IT operations. Instead of following a step-by-step tutorial, I designed this environment to simulate the infrastructure of a small-to-medium business. The goal of this project is to gain practical experience with technologies commonly used by Help Desk Technicians, IT Support Specialists, Systems Administrators, and Cloud professionals.

Documentation & Project Development

Throughout the development of this lab, I documented my configurations, troubleshooting processes, and technical decisions using Obsidian as my primary knowledge management tool. After organizing and refining my documentation, I transferred my completed notes and project documentation to GitHub to create a public portfolio that demonstrates my technical workflow, attention to detail, and ability to professionally document IT environments.

Current Environment

  • Windows Server 2022 Datacenter running in Microsoft Azure as my Domain Controller and DNS server (LABDC01).
  • Windows 11 Pro ARM virtual machine running through VMware Fusion on my MacBook Air (M2).
  • Azure Student Subscription used for cloud resources and infrastructure management.

Current Accomplishments

  • Installed and configured Active Directory Domain Services (AD DS).
  • Promoted the server into a functional Domain Controller environment.
  • Configured DNS services and network settings including static IP addressing.
  • Designed an organized Organizational Unit (OU) structure.
  • Created professional documentation covering configurations, troubleshooting steps, and deployment decisions.

Planned Expansion

Future improvements for this lab include Azure integration, PowerShell automation, Group Policy management, user administration, file shares with NTFS permissions, Windows security hardening, service accounts, backup strategies, monitoring, remote administration, troubleshooting scenarios, and additional enterprise documentation.
